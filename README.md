# developersb_work

「Spring Boot演習」の講義用コードおよび練習問題の解答用コードをまとめたリポジトリです。

# 概要

本リポジトリは、「Spring Boot演習」の講義用コードおよび練習問題の解答用コードを含む構成となっています。

# 使用技術

- IntelliJ IDEA 2026.1
- Maven 3.9.14
- OpenJDK 21.0.8
- Git/GitHub

# このプロジェクトの目的

- 講義で学んだ内容をもとに自分の力で実装する力を身につけることができます。
- 各章の練習問題を取り組むことでSpring Bootの理解を深めることができます。
